# Mini-Projeto 3: Atenção em Séries Temporais Climáticas

**Disciplina:** Inteligência Artificial (PGC112 / PPGCO — UFU)  
**Professor:** Gilberto Medeiros Nakamura  

---

## Visão Geral

Este projeto aborda a arquitetura **Transformer** com codificadores bidirecionais e mecanismo de autoatenção (*self-attention*) aplicada à previsão multivariada da série temporal climática **Jena Climate (2009–2016)**.

O detalhamento dos requisitos e o plano de estudos estão documentados em [**METODOLOGIA.md**](./METODOLOGIA.md).
